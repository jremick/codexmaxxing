# Publication Review

Use this checklist before making the repo public or copying material into a public site.

## Private Detail Scan

- No local home paths or usernames.
- No private hostnames, device names, internal domains, or network details.
- No API keys, tokens, secrets, auth references, or credential-loading commands.
- No client, employer, or non-public project names.
- No screenshots or logs that expose private tabs, paths, IDs, or account details.

## Content Quality Scan

- Each guide has a clear reader and task.
- Product-specific claims have a current source and verification date.
- Examples are generic enough to reuse outside this machine.
- Advice includes a check, proof point, or failure mode.
- The README points to the strongest entry points.

## Release Decision

Keep this file as the final review surface before public release. Add dated notes here when release candidates are checked.
