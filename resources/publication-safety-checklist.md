# Publication Safety Checklist

Run this before publishing guides, examples, screenshots, or repository content.

## Scan

- Local paths and usernames removed.
- Secrets, tokens, auth commands, and credential references removed.
- Client, employer, and private project names removed unless explicitly approved.
- Screenshots do not expose private tabs, accounts, IDs, paths, or logs.
- Examples use generic domains, repos, users, and data.
- Product-specific claims include a current source and date.

## Decide

- Publish as-is.
- Revise and re-check.
- Keep private.

## Record

For public releases, add a short dated note to [Publication Review](../docs/publication-review.md).
