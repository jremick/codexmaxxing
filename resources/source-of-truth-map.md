# Source Of Truth Map

Use this when a task spans repos, docs, live systems, or memory.

```markdown
Task:
Thinking altitude:

Current user instruction:

Authoritative source:

Supporting sources:

Volatile facts to recheck:

Sources that are background only:

Sources to ignore:

Conflict rule:

Verification evidence:
```

## Conflict Rule Examples

- Current user instruction beats older repo docs.
- Live production read-back beats a cached status note.
- Official vendor docs beat remembered API behavior.
- Tests beat a visual guess for code behavior.
- Browser screenshot beats assumed responsive layout.
